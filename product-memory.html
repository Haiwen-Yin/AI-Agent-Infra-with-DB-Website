Agent 私有记忆：独立保存，按归属读取Private Agent memory: save independently, read by current ownership

Agent 无须加入频道即可通过独立记忆接口保存、回读私有记忆，不混入知识库。当前主负责人具备记忆读取与安全域授权时可查看，归属转移后重新判定。页面继续按当前视图加载；图预览数不代表全库总数。新注册 Agent 显式获得 OWNED 范围的 memory.read / memory.write，不复制 Human 角色。仅 Sponsor 或同组织关系不授予私有读取权，旧负责人在转移后不再凭原归属读取。频道共享和知识晋升继续沿用候选、审核与显式发布。Agents can save and read private memory through a dedicated interface without joining a Channel or creating Knowledge. The current primary Human owner needs memory-read and Domain authority; ownership changes trigger a fresh decision. Views load on demand, and graph-preview counts are not corpus totals. New Agents receive OWNED memory.read / memory.write without copying Human roles. Sponsor status, organization membership or former ownership does not grant private reads. Channel sharing and Knowledge promotion retain candidate, review and explicit publication workflows.

v5.0.1 · 工作记忆与便签v5.0.1 · Memory and working notes

让交接结论保留版本、来源和适用边界Keep versions, sources and applicability with handoff findings

记忆记录事件、观察和适用时间，版本协调需独立审核，历史恢复生成新的后继版本。工作便签绑定确切工作和来源版本，可记录发现、未决问题和下一步；便签到期或退役后保留历史，不自动发布为长期记忆。Memory records event, observation and applicability times. Reconciliation requires independent review; history restoration creates a new successor version. Working notes bind exact Work and source revisions for findings, open questions and next actions. Expired or retired notes retain history and never publish themselves as long-term Memory.

v5.0.1 · Agent 资产与上下文v5.0.1 · Agent assets and context

先选择确切依据，再按预算组装上下文Select exact evidence before assembling a bounded context

为 Agent 绑定获授权的记忆、知识、Skill 和来源版本，结合查询、用途与优先级选择元数据和内容。模型输入预算保留必需指令与约束，分别记录内容表示与实际交付事实；资产绑定不新增来源权限，每次使用仍复核授权。Bind authorized Memory, Knowledge, Skills and source revisions to an Agent. Select metadata and content using the query, purpose and priority. Model-input budgets retain required instructions and constraints, with separate records for content representation and actual delivery. Asset bindings grant no additional source permissions; authorization is rechecked at use time.

上下文与数据库批处理Context and database batching

批量读取来源、权限与内容表示，并在事务中批量写入；相同内容减少重复输入，同时保留来源标识、义务与当前授权，工具和 Skill 按预算加载。Batch source, permission and representation reads and transactional writes. Deduplicate equal input bodies while retaining identities, obligations and current authorization; load Tools and Skills within budget.

Memory Ecosystem

记忆生态与接口验证Memory ecosystem and interface verification

通用接口兼容、已实现专用适配器与确切版本组合实测是不同结论。PowerContext、TencentDB Agent Memory 的接入及同时运行须按实际版本、接口、认证与部署组合验证；生态名称、Logo、链接或发现结果不能证明专用适配或联合验收。Generic interface compatibility, implemented dedicated adapters and verified exact-version combinations are distinct conclusions. PowerContext and TencentDB Agent Memory integrations, including running both together, require evidence for the actual versions, interfaces, authentication and deployment combination. Ecosystem names, logos, links and discovery do not prove a dedicated adapter or joint acceptance.
