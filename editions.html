GRAPH CAPABILITY MATRIX

受控与禁用能力Controlled and Disabled Capabilities

Manifest Draft Import、SLO 只读和 Checkpoint Fork 为 CONTROLLED；Replay、Dynamic Graph Migration、Framework Adapter Execution、A2A 与 OTLP 为 DISABLED。关闭能力不产生相应路由、Worker、调度或后台活动；组织架构、版本化记忆和核心恢复不依赖这些扩展。Manifest Draft Import, read-only SLO views, and Checkpoint Fork are CONTROLLED; Replay, Dynamic Graph migration, framework-adapter execution, A2A, and OTLP are DISABLED. Disabled capabilities create no corresponding routes, workers, schedules, or background activity; Organization, versioned memory, and core recovery do not depend on these extensions.

数据库适配Database Adapters

原生能力不同，共同产品契约一致Different Native Capabilities, One Product Contract

Oracle AI Database 26ai

Vector、Oracle Text、Property Graph / SQL PGQ、DBMS_SCHEDULER、数据库原生多租户及成熟高可用与备份生态。Vector, Oracle Text, Property Graph / SQL PGQ, DBMS_SCHEDULER, native multitenancy, and mature HA and backup options.

PostgreSQL 18.3

pgvector、tsvector、Apache AGE、pg_cron 和 RLS。当前以关系运行时为权威、AGE 为图投影；PostgreSQL 19 原生 Property Graph 作为后续适配目标。pgvector, tsvector, Apache AGE, pg_cron, and RLS. The relational runtime is authoritative and AGE is the graph projection; PostgreSQL 19 native Property Graph is a future adapter target.

YashanDB 23.5.4+

VECTOR + HNSW、SEARCH INDEX、原生 Property Graph、DBMS_SCHEDULER、LIST 分区、原生 JSON 转换与数据库加密包。VECTOR + HNSW, SEARCH INDEX, native Property Graph, DBMS_SCHEDULER, LIST partitioning, native JSON conversion, and database crypto packages.
