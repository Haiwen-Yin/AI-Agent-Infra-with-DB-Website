回答表达与证据边界Answer expression and evidence boundaries

将表达约束绑定到实际授权引用，区分原文、计算、推断、建议与未知。有限规则暂缓展示部分无依据的数字自信度、无效引用及缺少执行记录时的确定性否定结果；适用时展示授权原文，可能保守误拦。检查不等于逐句事实核验，也不提供校准后的正确概率。Bind expression constraints to actual authorized references; distinguish source statements, calculations, inference, advice and unknowns. Bounded rules withhold some unsupported self-confidence numbers, invalid references and categorical negative outcomes when execution records are missing, showing authorized extracts where applicable. Conservative false positives remain possible. These checks do not verify every claim or provide calibrated correctness probabilities.

保留任务与协议权威链Retain task and protocol authority

继续由数据库保存任务、来源修订、租约、凭证和未知结果。PostgreSQL 新增迁移 121，恢复 ACTIVE Agent 的原生上下文自读，不开放其他 Agent 的内容或写权限。上游协议与 Agent 框架的研究不等于新增支持，现有 MCP/A2A 的方法、传输与交互范围仍有明确限制。Keep Tasks, source revisions, leases, credentials and unknown outcomes in the authoritative database. PostgreSQL migration 121 restores ACTIVE Agents’ native reads of their own context without opening other Agents’ content or write access. Research into protocols and Agent frameworks establishes no additional support; existing MCP/A2A method, transport and interaction limits remain explicit.

私有记忆与按需读取Private memory and on-demand reads

Agent 无须加入频道即可通过独立记忆接口保存、回读私有记忆，不混入知识库。当前主负责人具备记忆读取与安全域授权时可查看，归属转移后重新判定。页面继续按当前视图加载；图预览数不代表全库总数。Agents can save and read private memory through a dedicated interface without joining a Channel or creating Knowledge. The current primary Human owner needs memory-read and Domain authority; ownership changes trigger a fresh decision. Views load on demand, and graph-preview counts are not corpus totals.

Grouped policies, assets, Domain filters and platform-Agent model settings retain shared UI and server-side authorization.

普通 HTTP 的浏览器兼容Browser compatibility on ordinary HTTP

缺少原生 UUID 接口时使用安全随机源生成请求身份，重试保留同一幂等标识；缺少安全随机源时受控报错。内容摘要提供兼容路径，这些改进不为 HTTP 增加传输加密。Generate request identities from secure randomness when native UUID support is absent and retain the same idempotency key on retries. Missing secure randomness produces a controlled error. Content hashing has a fallback; these improvements do not add transport encryption to HTTP.
